Description détaillée

Structure représentant les données d'un modèle 3D.

Le type geometry représente les données de vertex alloué sur la RAM. L'ensemble de ces vertex représente un modèle 3D.

Chaque geometry peut avoir une structure de vertex différente (avec normal, sans normal).
